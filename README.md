# Patient Health Risk Assessment System
# ระบบลงทะเบียนและประเมินความเสี่ยงสุขภาพเบื้องต้น

A web-based Patient Health Risk Assessment and Registration System built with React and Material UI (MUI).

## Features

- **Input Validation**: Validates patient data (name, surname, age, weight, height)
- **BMI Calculation**: Calculates BMI using the formula: `weight(kg) / (height(cm) / 100)²`
- **Risk Assessment**: Evaluates health risk based on BMI, smoking habits, and chronic diseases
- **3 Risk Levels**: Low Risk, Moderate Risk, High Risk
- **Result Summary**: Displays comprehensive patient data summary with risk level and recommendations

## MUI Components Used

- **Layout**: Container, Paper, Grid, Stack
- **Inputs**: TextField, RadioGroup/Radio, Select/MenuItem, Button
- **Feedback**: Alert, Dialog/DialogTitle/DialogContent/DialogActions, Chip
